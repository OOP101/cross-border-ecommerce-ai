# 项目介绍：国际贸易上市公司一站式智能服务平台

> 面向汇报与展示的项目全景介绍。技术细节见 [项目大纲](项目大纲.md)，需求与进度见 [需求文档](需求文档.md) / [目前进度](目前进度.md)。

---

## 一、项目定位

基于 **DeepSeek 大模型 + RAG + Agent** 的国际贸易一站式多语言智能营销与客服平台，让外贸企业「**单人驾驭多语言交流**」：智能客服自动应答、营销文案一键生成、30+ 语种精准翻译，降低对外贸业务员岗位的依赖。

## 二、业务痛点与解法

| 痛点 | 平台解法 |
|------|----------|
| 多语种市场都要配业务员，人力成本高 | AI 文案 + 翻译 + 客服，一人运营多语种市场 |
| 客服受时区/排班限制，无法 7×24 响应 | RAG 智能客服全天候即时应答，高风险自动转人工 |
| 产品知识、政策、话术散落个人，人员流动即流失 | 知识库统一沉淀，回答可溯源 |
| 外贸术语（FOB/CIF/LC）译法不一致 | 持久化术语库 + 翻译记忆，保证专业一致性 |

## 三、六大功能模块（全部可用）

1. **智能客服**：RAG 知识库问答 + 意图识别（订单/售后/产品/翻译）+ 高风险转人工 + **SSE 流式打字机输出**
2. **智能文案**：商品标题 / 详情 / 投放广告语 / 活动文案 / SEO 关键词，**多段并发生成**，模板卡片一键操作
3. **翻译引擎**：30+ 语种实时翻译 + 持久化术语库 + **两级翻译记忆（LRU + SQLite，跨重启命中）**
4. **知识库管理**：PDF/Word/MD/TXT/CSV 解析、清洗脱敏、语义分块、向量化，同名替换与精确删除
5. **数据洞察**：会话量 / 满意度 / 意图分布 / Token 成本看板（接入 LLM 真实 usage）
6. **管理后台**：JWT 鉴权、多角色权限、审计日志

## 四、系统架构

四层分层架构：**用户交互层（Vue 3）→ 服务编排层（Agent 意图路由）→ RAG 检索层（混合检索 + 重排序）→ 数据与模型层（向量库 / SQLite / DeepSeek）**。

- 问答链路：`提问 → 意图识别 → 混合检索（向量+BM25+RRF）→ 重排序 → 上下文拼接 → LLM 生成 → 溯源返回`（SSE 流式）
- 入库链路：`上传 → 解析 → 清洗（PII 脱敏）→ 语义分块 → 向量化 → 入库`

## 五、核心技术亮点

1. **可插拔架构**：LLM / Embedding / 向量库 / Agent 四大能力全部接口隔离，无 API Key 自动降级 Mock 全流程可跑；一个实现兼容 DeepSeek/通义千问/OpenAI/Moonshot 等所有 OpenAI 兼容厂商，改配置即切换。
2. **混合检索 + 评测驱动调优**：向量 + BM25 双路召回、RRF 融合；自建 52 条评测集驱动权重调优，**Recall@3 = 100%、MRR = 0.981**。
3. **性能优化组合拳**：BM25 索引缓存、向量矩阵缓存、文案 asyncio 并发（延迟从 4 段之和降为最慢一段）、SSE 流式首字秒出。
4. **多租户隔离**：知识库、会话、看板全链路按租户过滤，检索层防止跨租户知识泄漏。
5. **工程化**：23 项测试（冒烟 8 + 单元 12 + 租户隔离 3）、Alembic 数据库迁移、Docker 生产编排、跨平台一键启动器。
6. **安全**：PBKDF2 + HS256 JWT 零依赖实现、注册防提权 + 管理员授权、CORS 白名单自适应。

## 六、质量与验证

- 单元 12 项 + 冒烟 8 项 + 多租户隔离 3 项测试全部通过；前端构建通过
- RAG 评测：52 条用例 Recall@3 100%、MRR 0.981（评测脚本 `scripts/eval_rag.py` 可复跑）
- 5 轮迭代优化（安全 → 性能 → 体验 → 数据 → 前端），每轮均经回归验证
- 全流程浏览器实测：流式问答、一键文案、翻译记忆跨重启命中等均真实跑通

## 七、后续路线

- **L1（近期）**：真实 reranker 实测、真实 Embedding 接入与权重重调、成本看板租户化
- **L2（中期）**：Redis 缓存、限流与 Token 配额、LangGraph 多 Agent 编排、监控告警
- **L3（长期）**：微信/WhatsApp 渠道接入、MCP 工具化、多模态商品图理解

## 八、项目价值

以 AI 重构外贸「营销 - 翻译 - 客服」三大高频环节：知识资产平台化、响应 7×24、一人服务全球市场。同时它是一套**架构可演进的生产级工程框架**——可插拔设计支撑从演示到私有化部署的平滑升级。

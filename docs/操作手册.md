# 跨境电商一站式智能服务平台 - 操作手册

## 一、服务启动

### 1.1 一键启动
双击项目根目录的 `start.bat`，或命令行执行：
```bash
python launcher.py start
```

### 1.2 服务地址
| 服务 | 地址 | 说明 |
|------|------|------|
| 前端页面 | http://localhost:5174 | Vue3 用户界面 |
| 后端 API | http://localhost:8009 | FastAPI 服务 |
| API 文档 | http://localhost:8009/docs | Swagger 交互式文档 |
| 健康检查 | http://localhost:8009/health | 服务状态检测 |

### 1.3 停止服务
```bash
python launcher.py stop
```

## 二、用户认证

### 2.1 默认配置
当前系统运行在 **演示模式**（`AUTH_REQUIRED=False`），无需登录即可使用所有功能。

如需开启鉴权，修改 `backend/.env`：
```env
AUTH_REQUIRED=True
```

### 2.2 用户注册
**接口**：`POST /api/v1/auth/register`

**请求示例**：
```bash
curl -X POST http://localhost:8009/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "admin123"
  }'
```

**响应**：
```json
{
  "ok": true,
  "username": "admin",
  "role": "operator"
}
```

### 2.3 用户登录
**接口**：`POST /api/v1/auth/login`

**请求示例**：
```bash
curl -X POST http://localhost:8009/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "admin123"
  }'
```

**响应**：
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_min": 1440
}
```

### 2.4 使用 Token
开启鉴权后，所有受保护接口需在请求头携带 Token：
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8009/api/v1/copywriting/generate
```

### 2.5 角色说明
| 角色 | 权限 |
|------|------|
| `admin` | 全部功能，可授予其他用户角色 |
| `operator` | 常规操作权限 |
| `viewer` | 只读权限 |

授予角色（仅管理员可操作）：
```bash
POST /api/v1/auth/grant-role?username=admin&role=admin
```

## 三、功能模块

### 3.1 AI 文案生成
**接口**：`POST /api/v1/copywriting/generate`

**功能**：基于商品信息生成多语言营销文案（标题、描述、广告语、SEO 关键词）

**请求示例**：
```json
{
  "product_name": "智能手表",
  "category": "电子产品",
  "selling_points": "心率监测, 防水, 长续航",
  "target_market": "美国",
  "target_language": "en",
  "copy_type": "product"
}
```

**copy_type 类型**：
- `product`：商品标题 + 描述 + 关键词
- `ad`：广告语
- `campaign`：营销活动文案
- `keywords`：SEO 关键词
- `all`：全部类型

### 3.2 多语言翻译
**接口**：`POST /api/v1/translation/translate`

**功能**：支持术语库和翻译记忆的专业翻译

**请求示例**：
```json
{
  "text": "跨境电商一站式智能服务平台",
  "source_language": "zh",
  "target_language": "en",
  "use_terminology": true,
  "use_memory": true
}
```

### 3.3 RAG 智能客服
**接口**：`POST /api/v1/chat`

**功能**：基于知识库的问答系统，支持多轮对话

**请求示例**：
```json
{
  "message": "如何提升商品转化率？",
  "session_id": "session_001",
  "history": []
}
```

### 3.4 知识库管理
- 上传文档：`POST /api/v1/knowledge/upload`
- 搜索知识：`POST /api/v1/knowledge/search`
- 查看文档列表：`GET /api/v1/knowledge/documents`

### 3.5 数据洞察
- 运营看板：`GET /api/v1/analytics/dashboard`
- 高频问题：`GET /api/v1/analytics/top-questions`

## 四、亚马逊 SP-API 对接

### 4.1 配置凭证
在 `backend/.env` 中添加：
```env
# LWA 凭证（在 Amazon Seller Central 注册开发者后获取）
AMAZON_LWA_CLIENT_ID=your_client_id
AMAZON_LWA_CLIENT_SECRET=your_client_secret
AMAZON_LWA_REFRESH_TOKEN=your_refresh_token

# AWS IAM 凭证（用于 Signature V4 签名）
AMAZON_AWS_ACCESS_KEY=your_aws_access_key
AMAZON_AWS_SECRET_KEY=your_aws_secret_key
AMAZON_AWS_REGION=us-east-1

# 默认站点
AMAZON_DEFAULT_MARKETPLACE=US
```

### 4.2 OAuth 授权流程
1. 获取授权 URL：`GET /api/v1/amazon/oauth/authorize`
2. 卖家在亚马逊页面授权
3. 回调处理：`GET /api/v1/amazon/oauth/callback`

### 4.3 支持站点
`GET /api/v1/amazon/marketplaces`

支持 10 个站点：US、CA、UK、DE、FR、IT、ES、JP、AU、IN

### 4.4 订单管理
- 获取订单列表：`GET /api/v1/amazon/orders`
- 订单详情：`GET /api/v1/amazon/orders/{order_id}`
- 订单商品：`GET /api/v1/amazon/orders/{order_id}/items`

### 4.5 商品目录
- 搜索商品：`GET /api/v1/amazon/catalog/search?keywords=xxx`
- 商品详情：`GET /api/v1/amazon/catalog/{asin}`

### 4.6 库存管理
- FBA 库存汇总：`GET /api/v1/amazon/inventory/summary`

### 4.7 报表
- 创建报表：`POST /api/v1/amazon/reports`
- 查询状态：`GET /api/v1/amazon/reports/{report_id}`
- 下载文档：`GET /api/v1/amazon/reports/documents/{document_id}`

## 五、AI 与订单数据联动

### 5.1 订单智能分析
**接口**：`GET /api/v1/amazon/ai/analyze-orders`

**功能**：基于订单数据生成 AI 销售分析报告

**参数**：
- `marketplace`：站点代码（如 US、UK）
- `days`：分析天数（默认 7 天）

**返回**：
- 订单量趋势
- 热销商品 Top N
- 客单价分析
- AI 生成的洞察和建议

### 5.2 热销商品文案生成
**接口**：`POST /api/v1/amazon/ai/generate-copy-from-orders`

**功能**：从热销订单中提取商品信息，自动生成多语言营销文案

**参数**：
- `marketplace`：站点代码
- `days`：订单天数范围
- `top_n`：热销商品数量（默认 5）
- `target_language`：目标语言

### 5.3 客服订单上下文
**接口**：`GET /api/v1/amazon/ai/order-context/{order_id}`

**功能**：为智能客服提供订单上下文，支持订单相关问题的自动回答

### 5.4 商品描述翻译
**接口**：`POST /api/v1/amazon/ai/translate-order-descriptions`

**功能**：批量翻译订单中的商品描述

**请求示例**：
```json
{
  "asin_list": ["B08N5WRWNW", "B07XJ8C8F5"],
  "target_language": "zh",
  "marketplace": "US"
}
```

## 六、常见问题

### 6.1 端口冲突
修改 `launcher.py` 中的端口配置：
```python
BACKEND_PORT = 8009  # 后端端口
FRONTEND_PORT = 5174  # 前端端口
```

### 6.2 依赖安装失败
SP-API 相关包需从官方 PyPI 安装，启动器已自动处理。如仍有问题，手动执行：
```bash
cd backend
.venv\Scripts\pip install python-amazon-sp-api boto3 -i https://pypi.org/simple/
```

### 6.3 数据库初始化
首次启动会自动创建 SQLite 数据库（`backend/data/app.db`），无需手动操作。

### 6.4 LLM 配置
修改 `backend/.env`：
```env
LLM_PROVIDER=openai_compatible
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-v4-pro
```

## 七、技术架构

```
跨境电商一站式智能服务平台/
├── backend/                 # FastAPI 后端
│   ├── app/
│   │   ├── api/v1/         # API 路由层
│   │   ├── core/           # 核心模块（LLM、向量库、亚马逊）
│   │   ├── services/       # 业务逻辑层
│   │   └── db/             # 数据库模型
│   └── requirements.txt
├── frontend/               # Vue3 前端
├── docs/                   # 项目文档
└── launcher.py            # 一键启动器
```

**核心技术栈**：
- 后端：FastAPI + SQLAlchemy + SQLite
- 前端：Vue3 + Vite
- AI：OpenAI 兼容接口（支持 DeepSeek、OpenAI 等）
- 向量库：ChromaDB（可选）
- 亚马逊：SP-API（python-amazon-sp-api）

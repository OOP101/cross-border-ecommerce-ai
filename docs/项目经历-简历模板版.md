## 国际贸易上市公司一站式智能服务平台　　　AI大模型应用开发工程师　　　2026/08 - 至今

### 项目背景：

针对外贸企业多语言沟通成本高、营销文案制作依赖资深业务员、客户咨询响应慢、企业知识难以沉淀等问题，设计并开发基于 DeepSeek 大模型 + RAG + Agent 的一站式外贸智能服务平台。系统通过 RAG 检索增强生成实现可溯源的企业知识问答客服，通过持久化术语库与翻译记忆保证 30+ 语种译法一致性，覆盖智能客服、多语言翻译、智能文案生成、知识库管理、数据洞察与管理后台六大模块，帮助外贸企业"单人驾驭多语言交流"，降低对外贸业务员岗位的依赖。

### 主要职责：

- 设计并实现平台整体架构，采用交互层 / 编排层 / RAG 检索层 / 数据模型层四层架构，基于 FastAPI 完成六大模块 REST API；设计 LLM / Embedding / 向量库**可插拔抽象层**（工厂模式），默认 Mock 实现保证无 API Key 即可跑通全链路，修改配置即可无缝切换 DeepSeek、通义千问等真实模型。

- 构建外贸领域 RAG 知识库，设计文档处理流程，实现 PDF、DOCX、TXT、CSV、Markdown 等资料解析、文本清洗（含 PII 脱敏）、语义分块、Embedding 生成和知识入库；结合向量检索 + **BM25 关键词检索 + RRF 融合排序 + 可插拔重排序**构建 Hybrid Retrieval 混合检索体系，回答支持知识溯源。

- 主导 RAG 检索性能优化，BM25 索引按语料指纹缓存（文档增删自动失效重建）、向量库归一化矩阵缓存，消除每次查询的全量重建开销；文档按 doc_id 精确增删、同名自动替换，保证知识库一致性。

- 开发智能客服 Agent，实现规则意图识别（订单 / 售后 / 产品 / 翻译）、高风险问题自动转人工、多轮上下文管理；实现 **SSE 流式输出接口**与前端打字机渲染，大幅降低长回答等待感。

- 开发多语言翻译引擎，设计**持久化术语库**（FOB/CIF/LC 等外贸术语）注入 Prompt 保证专业译法跨语言一致；实现「进程内 LRU + SQLite 持久化」**两级翻译记忆缓存**，跨重启命中，重复文本零模型调用成本。

- 开发智能文案生成模块，支持商品标题、详情描述、投放广告语、SEO 标签一键生成；基于 asyncio.gather + 异步 LLM 调用实现**多段文案并发生成**，生成延迟从四段串行之和降为最慢一段。

- 设计鉴权与安全体系，基于 PBKDF2 + HS256 JWT 实现零第三方依赖认证，多角色权限控制（注册防自助提权、管理员专用角色授予接口）、CORS 白名单自适应。

- 建立可观测性与工程化体系，Token 用量接入 LLM 真实 usage 支撑成本看板；编写 20 项冒烟 + 单元测试；实现 Docker 编排与 Windows/POSIX 跨平台一键启动器。

### 项目难点：

- 单一大模型服务需同时支撑智能问答、文案生成、实时翻译等多个场景，文案"一键生成"需串行调用 4 次 LLM 导致延迟叠加。通过 asyncio.gather 并发生成 + SSE 流式推送解决，多段生成延迟从串行之和降为最慢单段，客服场景实现逐字输出。

- 外贸场景专业术语密集（FOB、CIF、L/C、MOQ 等），同一术语多语言译法不一致会直接影响合同与沟通准确性；传统关键词检索也容易遗漏语义相关知识。通过数据库持久化术语库注入 Prompt 强约束译法 + 向量/BM25 双路检索 RRF 融合解决，答案附带知识来源可溯源。

- 知识库文档增删频繁，检索索引（BM25 统计量、向量矩阵）若每次查询全量重建，随知识库增长问答延迟将持续劣化。通过语料指纹缓存 + 增删失效重建、向量归一化矩阵惰性缓存解决，检索热路径无全量重建开销。

- 大模型存在幻觉风险，商业客服场景不能给出无依据回答；同时高风险问题（投诉、退款、法律）不宜由 AI 处理。通过 RAG 溯源 + 关键词规则识别自动转人工兜底解决。

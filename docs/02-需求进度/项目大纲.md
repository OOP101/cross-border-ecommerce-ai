# 项目大纲：国际贸易上市公司一站式智能服务平台

> 一句话定位：基于 **DeepSeek / 小米 MiMo 大模型 + RAG + Agent** 的国际贸易一站式多语言智能营销与客服平台，目标是「单人驾驭多语言交流」。当前版本 **v0.2（待孵化）**。

---

## 一、背景与目标

外贸企业普遍面临**多国家、多地区、多语言**的服务与营销挑战，传统模式高度依赖外贸业务员：人力成本高（人员扩张与业务线性挂钩）、响应慢（无法 7×24 覆盖时区）、知识传承难（知识散落在个人经验中）。

平台用 LLM + RAG 重构这套流程，实现三大核心能力：

1. **智能化文案创作**——多语言营销文案自动生成（商品描述 / 广告语 / 活动文案 / SEO 标签）；
2. **精准多语言服务**——30+ 语种实时翻译 + 术语库 + 翻译记忆；
3. **智能客户服务**——基于企业私有知识库的 RAG 问答，答案可溯源、高风险自动转人工。

## 二、系统架构（四层）

```
┌─────────────────────────────────────────────────────────┐
│ 用户交互层：Vue 3 Web端 / REST API / 微信 / WhatsApp（预留）│
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 服务编排层：意图识别 / 上下文管理 / Agent 工作流(LangGraph)  │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ RAG 检索层：混合检索(向量+BM25) / RRF融合 / 重排序 / 溯源    │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 数据与模型层：向量库 / 知识库 / LLM(DeepSeek) / 翻译 / 缓存  │
└─────────────────────────────────────────────────────────┘
```

**核心链路**

- RAG 问答：`用户输入 → 意图识别 → 混合检索 → RRF 融合 → 重排序 → 上下文拼接 → LLM 生成 → 溯源返回`（支持 SSE 流式）
- 知识入库：`文档上传 → 格式解析 → 清洗(含 PII 脱敏) → 语义分块(500字/128重叠) → 向量嵌入 → 向量存储`

## 三、核心功能模块

| 模块 | 核心能力 | 关键实现 |
|------|----------|----------|
| 智能客服 | RAG 问答、多轮对话、知识溯源、转人工、**SSE 流式打字机** | 混合检索 + Agent 意图路由 + 前端快捷指令卡片 |
| 知识库管理 | PDF/Word/MD/TXT/CSV 上传、清洗、分块、向量化 | 语义分块 + doc_id 精确增删 + 租户内同名替换 |
| 翻译引擎 | 30+ 语种实时翻译、术语库、**两级翻译记忆** | 术语注入 Prompt + LRU + SQLite 持久化（跨重启命中） |
| 智能文案 | 商品描述 / 广告语 / 活动文案 / SEO 标签，多语言 | **asyncio 多段并发生成** + 模板卡片一键填充 |
| 数据洞察 | 会话量 / 满意度 / 意图分布 / Token 成本看板 | SQL 聚合 + ECharts + LLM 真实 usage |
| 管理后台 | 系统状态、知识统计、审计日志、JWT 鉴权、备用端点展示 | 多角色权限控制 + 注册防提权 |

## 四、技术栈

**FastAPI (Python 3.11+) + Vue 3 + Element Plus + SQLAlchemy/SQLite + DeepSeek / 小米 MiMo**；LLM / Embedding / 向量库 / Agent 全部可插拔（Mock 优先，配置即切真实模型）；Docker 生产编排 + 跨平台一键启动器（`launcher.py`）+ Alembic 数据库迁移。

## 五、可插拔设计（核心创新）

| 能力 | 接口位置 | 可选实现 |
|------|----------|----------|
| LLM | `core/llm` | mock / openai_compatible（DeepSeek、小米 MiMo、通义千问、硅基流动等） |
| Embedding | `core/embeddings` | mock / openai_compatible / sentence-transformers |
| 向量库 | `core/vector_store` | memory / chroma（可扩展 Milvus） |
| Agent | `services/agent` | 规则路由 / LangGraph 图编排 |

无 API Key 时自动降级 Mock，**任何环境可运行、可演示、可测试**。

**多厂商与故障转移**：主端点当前为小米 MiMo（`mimo-v2.5-pro`），备用端点 DeepSeek（`v4-flash`）——通过 `LLM_FAILOVER` 配置端点链，主端点连接失败 / 超时 / 限流 / 密钥失效时自动秒级切换，流式接口同样生效。换厂商 = 改三行配置；接硅基流动还可在 DeepSeek / Qwen / GLM / Kimi 间一个 Key 随意切换。

**质量基线**：52 条评测集 Recall@3 = 100%、MRR = 0.981（`scripts/eval_rag.py` 可复跑）；23 项自动化测试（单元 14 + 冒烟 8 + 租户隔离 3）。

## 六、多租户与安全

- `tenant_id` 贯穿知识库、会话、看板全链路，检索层过滤候选阻断跨租户知识泄漏；
- JWT（PBKDF2 + HS256，零第三方依赖）、注册防自助提权 + 管理员授权接口、CORS 白名单自适应、PII 脱敏、审计日志。

## 八、启动方式

```bash
# 方式一：一键启动（自动建 venv、装依赖、拉起前后端）
python launcher.py

# 方式二：手动
cd backend  && pip install -r requirements.txt && uvicorn app.main:app --reload --port 8009
cd frontend && npm install && npm run dev
```

- 前端 http://localhost:5173 ，接口文档 http://localhost:8009/docs
- 默认管理员 `admin / admin123`（生产务必修改）；`AUTH_REQUIRED=true` 开启鉴权

# 需求文档：国际贸易上市公司一站式智能服务平台

> PRD 精简版：需求范围、优先级、非功能指标、API 清单。项目背景与架构见 [项目大纲](项目大纲.md)，实现进度见 [目前进度](目前进度.md)。

---

## 一、项目目标

1. **智能化文案创作**：LLM 多语言营销文案自动生成，覆盖商品上架、广告、活动页全链路。
2. **精准多语言服务**：30+ 语种实时翻译与本地化，专业术语译法一致。
3. **智能客户服务**：RAG 构建企业私有知识库，精准、可溯源的智能问答。
4. **数据驱动营销**：运营数据看板支撑营销决策。
5. **持续迭代优化**：反馈评估驱动的模型与知识库持续优化。

## 三、非功能需求

| 类别 | 指标 / 要求 |
|------|-------------|
| 性能 | 问答 P95 ≤ 3s；检索延迟 ≤ 500ms；500+ 并发会话 |
| 安全 | JWT 鉴权、CORS 白名单、PII 脱敏、注册防提权、审计日志 |
| 合规 | 遵循 GDPR/CCPA；支持私有化部署，关键数据不出境 |
| 可扩展 | LLM / Embedding / 向量库 / Agent 全部可插拔，配置切换 |
| 部署 | Docker 编排；硬件 8 核 16G 起，支持峰值 500 次/分钟 |

## 五、术语表

完整名词解释见 [专业名词解释](专业名词解释.md)（按大模型基础 / RAG 检索 / 工程架构 / 安全分组，含项目内位置）。

| 术语 | 一句话解释 |
|------|------|
| RAG | 检索增强生成：检索外部知识辅助 LLM 生成，答案可溯源 |
| Hybrid Retrieval | 混合检索：向量语义 + BM25 关键词双路召回，RRF 融合排序 |
| 翻译记忆 | 历史译文两级缓存（LRU + SQLite），同句重译零成本且保证一致 |
| 故障转移 | 主 LLM 端点异常时自动切换备用端点（MiMo ↔ DeepSeek） |
| 多租户 | 一套系统服务多家公司，tenant_id 全链路数据隔离 |

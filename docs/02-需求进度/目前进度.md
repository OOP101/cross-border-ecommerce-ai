# 目前进度：国际贸易上市公司一站式智能服务平台

> 截至 2026-08-29，版本 v0.2（待孵化）。本文档为进度与待办的**唯一维护入口**（合并原版本规划、优化方案、进度汇报三份文档）。

---

## 一、当前状态总览

**六大功能模块全部可用**：智能客服（RAG + SSE 流式）、知识库管理、多语言翻译（术语库 + 持久化翻译记忆）、智能文案（并发生成）、数据洞察、管理后台（JWT 鉴权）。

- 默认接入 **DeepSeek 真实模型**，无 Key 自动降级 Mock，全流程可跑通
- **测试**：冒烟 8 项 + 单元 12 项，全部通过；前端 `npm run build` 通过
- **安全**：注册防提权、CORS 白名单自适应、PBKDF2 + HS256 JWT（零第三方依赖）
- **性能**：BM25 索引缓存、向量矩阵缓存、文案多段并发、SSE 流式均已落地

## 三、待办清单（按优先级，唯一维护入口）

### L1 · 高优先级（下一迭代，1-2 周）

| 事项 | 说明 |
|------|------|
| cross_encoder 实测 | 安装 sentence-transformers + 下载 bge-reranker（约 2GB），对比启用前后的检索指标 |
| 真实 Embedding 接入与权重重调 | 配置 DashScope 等 Embedding Key 后重跑 `scripts/eval_rag.py`，重调混合检索权重（当前 0.4/0.6 为 Mock Embedding 实测最优） |
| ApiUsage 租户化 | 用量表加 `tenant_id` 列，Token 成本看板按租户统计 |

### L2 · 中优先级（1-2 个月）

- Redis：会话状态、翻译记忆、索引共享（多实例部署前提）
- 限流与 Token 配额（防滥用与成本失控）
- LangGraph 图编排升级（接口已预留）
- 监控告警（Prometheus + Grafana）；流式覆盖翻译/文案
- 审计日志中间件统一埋点；高频问答缓存
- 数据库生产化：SQLite → PostgreSQL（改 `DATABASE_URL` 即可）

### L3 · 低优先级 / 长期

- 渠道扩展（微信 / WhatsApp）；MCP 工具化；多模态商品图理解
- 查询改写（Multi-Query）、情感分析、翻译质量评估、知识库版本管理
- 内容安全输出侧四层过滤；向量库 Milvus 生产化

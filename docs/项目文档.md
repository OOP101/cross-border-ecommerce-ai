# 跨境电商一站式智能服务平台 · 项目文档

> 本文档为项目唯一权威文档，覆盖背景、架构、进度、踩坑、数据口径全维度。

---

## 一、项目概述

基于 **大模型 + RAG + Agent** 打造的一站式外贸智能服务平台，帮助外贸企业「单人驾驭多语言交流」，显著降低对外贸业务员岗位的依赖。四大能力（LLM/Embedding/向量库/Agent）工厂模式可插拔 + Mock 降级，无 API Key 也能完整跑通。

---

## 二、项目背景

外贸企业普遍面临**多国家、多地区、多语言**的服务与营销挑战：人力成本高（人员扩张与业务线性挂钩）、响应慢（无法 7×24 覆盖时区）、知识传承难（知识散落在个人经验中）。平台用 LLM + RAG 重构这套流程，实现三大核心能力：

1. **智能化文案创作**——多语言营销文案自动生成（商品描述 / 广告语 / 活动文案 / SEO 标签）
2. **精准多语言服务**——多语种实时翻译 + 术语库 + 翻译记忆
3. **智能客户服务**——基于企业私有知识库的 RAG 问答，答案可溯源

## 六、架构设计

**四层架构**：

```
用户交互层   Vue3 Web端 | REST API | 微信/WhatsApp（预留）
服务编排层   意图识别 | 上下文管理 | Agent 工作流
RAG检索层    混合检索(向量+BM25) | RRF融合 | 重排序 | 溯源
数据模型层   向量库 | 知识库 | LLM | 翻译 | 缓存
```

**RAG 问答链路**：`用户输入 → 意图识别 → 混合检索 → RRF 融合(K=60) → 重排序 → 上下文拼接 → LLM 生成 → 溯源返回`（支持 SSE 流式）

**知识入库链路**：`文档上传 → 格式解析 → 清洗(含 PII 脱敏) → 语义分块(500字/128重叠) → 向量嵌入 → 向量存储`

**质量基线**：52 条评测集当前全命中：Recall@3 = 100%、MRR = 0.942（2026-09-17 复核实测，`scripts/eval_rag.py` 可复跑）

## 八、踩坑记录

1. **前端误报文案失败**：axios 60s 超时 < 全套文案生成 90s+ → 放宽至 3 分钟。
2. **流式落库崩溃**：FastAPI 依赖注入的 db 会话在流式响应结束即关闭 → 独立 `SessionLocal()`。
3. **检索延迟线性劣化**：每次查询全量重建 BM25 + np.stack 重拼矩阵 → 指纹缓存 + 惰性缓存（失效挂写路径，不靠 TTL）。
4. **注册越权**：`role=req.role or "operator"` 信任客户端，任何人传 admin 自助提权 → 服务端强制 + schema 删字段 + grant-role 仅 admin。
5. **CORS 全挂**：`allow_origins=["*"]` + `allow_credentials=True` 被浏览器规范禁止 → 白名单才开凭据。
6. **启动器中文 Windows 崩溃**：netstat GBK 输出按 UTF-8 解码报错 + wmic 弃用 → 字节流容错解码 + 改 PowerShell CIM。
7. **流式 Token 是估算**：SSE 拿不到 usage → 非流式路径取真实值，后续 stream_options。
8. **Mock Embedding 向量路是噪声**：评测集发现权重 0.6/0.4 不合理 → 调为 0.4/0.6（BM25 权重更高），Recall@3 96.2%→100%。

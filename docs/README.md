## 项目速览

- **项目名称**：国际贸易上市公司一站式智能服务平台
- **技术栈**：FastAPI (Python 3.11+) + Vue 3 + Element Plus + RAG + Agent（DeepSeek，可插拔）
- **核心能力**：智能客服（SSE 流式）/ 多语言翻译 / 智能文案 / 知识库管理 / 数据洞察 / 管理后台
- **当前状态**：六大模块全部可用，两轮安全/性能/体验优化完成，测试 20 项通过
- **服务端口**：后端 8009，前端 dev 5173

# 国际贸易常见问题（FAQ）

## 订单与物流
1. 问：订单什么时候发货？
   答：现货商品在付款确认后 24-48 小时内发货；定制商品根据生产周期，一般为 7-15 个工作日。

2. 问：如何查询物流状态？
   答：您可以在订单详情页查看物流单号，或联系客服获取实时追踪信息。国际物流一般提供 DHL、FedEx、UPS 或海运选项。

3. 问：支持哪些发货方式？
   答：支持国际快递（DHL/FedEx/UPS）、空运、海运拼箱（LCL）和整柜（FCL），具体以商品页为准。

## 产品与认证
4. 问：产品有哪些国际认证？
   答：我司产品通过 CE、RoHS、FCC、FDA 等认证，具体认证信息可在商品详情或证书栏查询。

5. 问：最小起订量（MOQ）是多少？
   答：常规产品 MOQ 为 100 件起，支持混批；定制产品 MOQ 视工艺而定，可联系业务员洽谈。

## 支付与价格
6. 问：支持哪些支付方式？
   答：支持 T/T 电汇、信用证（L/C）、PayPal、西联汇款等，具体以合同约定为准。

7. 问：报价是否含运费和关税？
   答：FOB 报价不含运费和保险费；CIF 报价含运费与保险。进口关税由买方承担，可提供参考税率。

## 售后与退换
8. 问：收到商品有质量问题怎么办？
   答：请在签收后 7 天内拍照并联系售后，经核实属质量问题可退换或补发，退货运费由我方承担。

9. 问：退换货流程是怎样的？
   答：提交售后申请 → 提供凭证 → 审核 → 寄回/补发 → 退款或换货，全程可追踪。
